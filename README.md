# Interactive Onboarding Platform

MVP платформы интерактивного онбординга для классифайда.

## 📖 О проекте

Платформа помогает пользователям быстрее разбираться в интерфейсе классифайда через интерактивные подсказки. Администратор может создавать сценарии онбординга, публиковать их, отслеживать прохождение и видеть аналитику.

### Бизнес-задача

- Помочь пользователю быстрее разобраться в классифайде
- Дать продуктовой команде инструмент управления онбордингом
- Показать эффективность онбординга через аналитику и отчёты

### Проблема

Пользователи классифайдов с большим количеством функций часто теряются в интерфейсе. Они не понимают, как искать товары, размещать объявления, безопасно общаться. Это приводит к тому, что пользователь уходит раньше, чем увидит ценность сервиса.


## 🧩 Что реализовано в MVP

### Backend (Go + PostgreSQL + Docker)

- Управление проектами и элементами интерфейса
- Управление сценариями и шагами (статусы: in_development → enabled → disabled)
- Runtime API — поиск подходящего сценария для SDK
- Tracking — создание сессий и приём событий
- Аналитика — completion_rate, skip_rate, drop_off_rate, среднее время
- PDF-отчёт по сценарию
- Мягкое удаление (soft delete) — история сохраняется
- OpenAPI 3.0.3

### Frontend (React + TypeScript)

- Админка для управления проектами и сценариями
- Редактирование шагов с привязкой к элементам интерфейса
- Публикация и управление статусами сценариев
- Просмотр аналитики и скачивание PDF-отчёта
- Тестовый сайт классифайда для проверки онбординга

### SDK / Виджет

- Встраивается на сайт через скрипт
- Показывает подсказки, привязанные к элементам интерфейса
- Отслеживает прохождение (шаги, завершение, пропуск)
- Поддерживает тестовый режим (test token)

## 🚀 Инструкция по запуску

**1. Клонировать репозиторий**

git clone https://github.com/DaniilSintsov/interactive-onboarding.git
cd interactive-onboarding

**2. Поднять сервисы через Docker Compose**

docker-compose up -d

**3. Применить миграции**

cd backend
goose -dir migrations postgres "postgres://..." up

**4. Запустить backend**

go run cmd/main.go

**5. Запустить frontend**

cd frontend
npm install
npm run dev

**6. Открыть в браузере**

- Админка: http://localhost:5173
- API: http://localhost:8080
- Тестовый сайт: http://localhost:3000


## 📡 API

Полная спецификация — backend/openapi.yaml

### Административные (/api/v1/)

- projects — управление проектами
- scenarios — управление сценариями
- steps — управление шагами
- analytics — аналитика
- report/pdf — PDF-отчёт

### Публичные (/api/v1/sdk/)

- resolve — поиск сценария для SDK
- sessions — создание сессии
- events — приём событий


## 📊 Аналитика и отчёты

### Доступные метрики

- completion_rate — доля завершённых сессий
- skip_rate — доля пропущенных сессий
- drop_off_rate — доля пользователей, не дошедших до следующего шага
- average_completion_time_seconds — среднее время прохождения

### PDF-отчёт

Генерируется по кнопке в админке и содержит:
- Общую статистику по сценарию
- Воронку прохождения по шагам
- Проценты завершения и оттока
